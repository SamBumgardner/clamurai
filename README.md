# Clamurai
A game originally created for the [Samurai Game Jam](https://itch.io/jam/samuraigamejam) in 14 days.

## Play the Game
[Play on itch.io](https://twistedhawk.itch.io/clamurai)

Enter a mysterious underwater world as a Clam-Samurai on a mission.

## How to Run Project Locally
To run the project locally:

1. Open the project with the Unity Hub application.
2. Expand the Project tab's folder tree to reach folder: `Assets` -> `Scenes`.
3. Double-click the `Scenes` folder to display its contents.
4. Double-click the `Title` scene to select the first scene of the game.
5. Click the play button in the top-center of the Unity editor.
